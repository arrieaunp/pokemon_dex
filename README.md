# 🧩 Pokédex Viewer (PokeAPI)

A simple web app that displays the first 151 Pokémon from the Kanto region using [PokeAPI](https://pokeapi.co/).

## 🔗 API Used

- List: `https://pokeapi.co/api/v2/pokemon?offset=0&limit=151`
- Detail: `https://pokeapi.co/api/v2/pokemon/{id}`

## ✅ Features

- Fetch and display 151 Pokémon with images
- Click to view details:
  - Name, ID, types
  - Height, weight
  - Base stats (HP, Attack, etc.)

## 💻 Tech Stack

- HTML / CSS / JavaScript
- Fetch API
